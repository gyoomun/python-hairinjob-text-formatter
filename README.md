# python-hairinjob-text-formatter

헤어인잡 업체 정보 텍스트 포맷터

## 기능

업체 정보 텍스트를 읽기 쉬운 형식으로 변환합니다.

### 변환 예시

**입력:**
```
알트리니떼
업체주소 서울 서초구 서래로6길 20 (반포동, 트리니티빌딩) 전화번호 02-533-3703 채용담당자 장효진 담당자연락처 0508-4850-9197 ※ 안심번호 이용 중
```

**출력:**
```
알트리니떼
업체주소: 서울 서초구 서래로6길 20 (반포동, 트리니티빌딩)
전화번호: 02-533-3703
채용담당자: 장효진
담당자연락처: 0508-4850-9197 ※ 안심번호 이용 중
```

## 사용 방법

### 1. 파일에서 읽기
```bash
python3 main.py input.txt
```

### 2. 리다이렉트로 읽기
```bash
python3 main.py < input.txt
```

### 3. 직접 입력
```bash
python3 main.py
# 텍스트를 입력한 후 Ctrl+D (Mac/Linux) 또는 Ctrl+Z (Windows)를 누르세요
```

## 출력

- 변환된 결과가 화면에 출력됩니다
- 결과가 `output.txt` 파일에 자동으로 저장됩니다

## 요구사항

- Python 3.x
